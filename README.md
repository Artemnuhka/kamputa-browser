# Сайт kamputa browser

Сайт и мастерская питомцев для kamputa browser. Рисунки из мастерской сохраняются на устройстве автора; для отправки заявки автор прикрепляет PNG к публичному обращению в GitHub Issues.

## Заявки на питомцев

Заявки находятся во вкладке Issues этого репозитория. Автор указывается по учётной записи GitHub. Просмотрите рисунок и условия его использования до принятия решения о публикации. Само создание заявки не добавляет питомца в браузер или каталог.

Маркетплейс и покупки находятся в разработке. Сайт пока не хранит балансы и не принимает оплату.
