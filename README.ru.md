# kamputa browser

Браузер для Linux на основе Firefox с компактным интерфейсом в духе Chromium / Helium и локальным пиксельным питомцем. Это перепакованная официальная сборка Mozilla с опубликованными изменениями интерфейса, а не отдельно скомпилированный движок Gecko. Проект независимый и не поддерживается Mozilla.

## Установка

Скачай пакет для своей системы в разделе [Releases](https://github.com/Artemnuhka/kamputa-browser/releases):

- **RPM (x86_64):** для Fedora и openSUSE. Установи через пакетный менеджер — он подтянет необходимые библиотеки.
- **DEB (amd64):** для Debian / Ubuntu. Команда установки: `sudo apt install ./kamputa-browser_0.5.1_amd64.deb`.
- **AppImage (x86_64):** разреши выполнение файла и запусти его. Если FUSE недоступен, используй `./kamputa-browser-0.5.1-x86_64.AppImage --appimage-extract-and-run`.

**Зависимости:**

- Python 3
- Bash
- GTK 3
- DBus

## Возможности

- Компактные тёмные вкладки и панель инструментов; также доступно классическое оформление.
- Нативные темы Firefox с готовыми палитрами и собственными цветами. Русский и английский текст Kamputa подстраивается под язык браузера.
- При первом запуске — импорт данных, выбор поиска, темы, необязательный вход в Mozilla и выбор менеджера паролей. При знакомстве с питомцем ему нужно дать имя.
- Локальный питомец с кормлением, играми, сном, прогулками и анимацией работы за ноутбуком. Его состояние хранится в профиле; он не читает сайты и историю посещений.
- По желанию — предложения деактивировать неиспользуемые вкладки с большим потреблением памяти. Значения памяти приблизительные. Активные, закреплённые и приватные вкладки, воспроизведение медиа и звонки защищены от выгрузки.
- Встроенный подписанный uBlock Origin без изменений. Телеметрия, исследования и рекламные предложения отключены политиками. Это не означает отключение всех сетевых сервисов Mozilla: Safe Browsing, обновления расширений, поиск и необязательная синхронизация аккаунта могут обращаться к сети.
- Обновления из стабильных GitHub Releases этого репозитория. Ежедневная проверка включается по желанию; загрузку и установку запускает пользователь. Пакеты проверяются по размеру и SHA-256 из манифеста. Доверие основано на HTTPS и этом репозитории; отдельного ключа подписи разработчика пока нет.

## Сборка из исходников

Для сборки нужны Python 3.12 или новее, Bash, `rpmbuild`, `dpkg-deb`, `mksquashfs` и официальный исполняемый файл `appimagetool` для создания AppImage.

```sh
python3 packaging/fetch-upstream.py --cache build/upstream
python3 build.py --firefox build/upstream/firefox
python3 packaging/build-packages.py --appimagetool /path/to/appimagetool.AppImage --runtime-file /path/to/runtime-x86_64
```

SHA-256 инструмента AppImage и его runtime зафиксированы в `packaging/TOOLCHAIN.json`; скрипт упаковки отклоняет другие бинарные файлы.

В `BUILD.json` зафиксированы точные версии и контрольные суммы Firefox, русского языкового пакета и uBlock. Скрипты сборки приводят оптимизированную структуру JAR Mozilla к виду, совместимому со стандартными ZIP-инструментами Python, заново применяют изменения оформления и сохраняют юридические уведомления движка. Gecko они не компилируют. Для самостоятельной сборки Gecko используй точные исходники и ревизию, указанные в [SOURCE-CODE.md](SOURCE-CODE.md).
